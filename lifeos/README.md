# Life OS — R0.1

Личные задачи. PWA: работает офлайн, данные только на телефоне (IndexedDB).
Без сборки и зависимостей: чистые HTML/JS.

## Проверка на телефоне (критерий R0)
1. Открыть ссылку в браузере телефона → «Добавить на главный экран».
2. Включить авиарежим, добавить 5 задач, отметить одну, закрыть и открыть приложение снова.
3. Данные на месте → R0 пройден.

## Локально
```bash
cd lifeos && python3 -m http.server 8080   # http://localhost:8080
node --test tests/events.test.mjs          # юнит-тесты
node tests/e2e.mjs                         # браузер, офлайн, экспорт/импорт (нужен playwright)
```

## Модель данных
Всё — события: `{id, type, ts, payload, source, confidence, evidence}`.
Задача = событие `type: "task"`. Новые модули (расходы, заметки, навыки) добавляются
новыми типами событий, без новых таблиц.
