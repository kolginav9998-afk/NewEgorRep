## 4. Пакет проверки складского ПК и принтера

**`tools/pc_check.py`** запускается из исходников WMS; рабочую папку WMS не трогает:
- **Среда:**
  - система, Python, LibreOffice (проверена ли версия), Python-UNO, Writer;
  - шрифты с кириллицей, локаль, место, Xvfb;
  - CUPS и принтеры, `/dev/usb/lp*` и права;
  - у каждой строки — «что сделать».
- **Компиляция** всех модулей WMS и всех книг WMS_TOOLBOX — в собственном невидимом дисплее Xvfb.
- **Наборы тестов:**
  - быстрая проверка — кандидат, перенос, Final Core, инструменты, сквозной тест, сам пакет;
  - `--full` — ещё этапы 5…1 и проверки окон.
- **Итог:**
  - `PC_CHECK_REPORT.md` и `pc_check.json`;
  - архив `<папка>.tar.gz` — отчёты и журналы тестов, без книг и профилей;
  - отпечаток исходников в начале и в конце;
  - код 0 / 1 / 2.

**`tools/printer_check.py`** печатает только тестовые этикетки (синтетические ЕИ фикстуры):
- без ключей — список принтеров CUPS и USB-устройств;
- `--cups ИМЯ` — PDF, собранный кнопками WMS_LABELS, уходит в `lp`;
- `--tspl /dev/usb/lp0` — команды TSPL для принтера без драйвера;
- `--pdf-only` — только макет, без печати.

После печати скрипт спрашивает, верно ли напечатано, и записывает ответ.

Проверка самого пакета — `tests/run_pc_tools.py` (P01–P02); настоящий принтер в тестах не используется.

**Итоговый полный набор M5 выполнен этим же пакетом** — `pc_check.py --full` в облачной среде (раздел 5).

### 6.2 Файл остатков для переноса

**Файл:** один файл — CSV (UTF-8 или Windows-1251, разделитель `;` или `,`), ODS или XLSX. Первая строка — заголовки; **одна строка — один физический остаток** (одна партия, одна наклейка).

| Колонка | Обязательно | Что писать |
|---|---|---|
| **ЕИ** | нет | номер старой наклейки: `12`, `ЕИ-12` или `ЕИ-00000012`; пусто — WMS выдаст новый номер выше всех (нужна новая наклейка). Один номер — одна строка |
| **Наименование** | да | как на складе |
| **Артикул** | для деталей — да | у деталей один артикул — один ЕИ |
| **Единица** | да | шт, м, кг, л, упак, пар, компл, рул, м2, м3, т, г, мл, см, мм, лист, набор, пог. м, бух; другую — прислать списком |
| **Количество** | да | не меньше 0, до 3 знаков после запятой; 0 — ЕИ сохраняется с нулевым остатком |
| **Место** | желательно | место хранения, как в списке мест (ниже) |
| **Категория** | нет | группа товара |
| **Тип источника** | да | Поставщик, Офис, Производство, Детали, Старый склад или Иной приход. Если колонки нет или она пуста — одно правило для всего файла (например, «всё — Старый склад»); это правило пользователь задаёт явно |
| **Старая маркировка** | нет | инвентарный номер или прежняя надпись |
| **Комментарий** | нет | любое примечание |

**Вместе с файлом:**
- **Список мест хранения** (по одному в строке) или разрешение принять все места из таблицы как есть.
- **Правило для пустого типа источника**, если он где-то пуст.
- **Единицы не из списка выше**, если они есть в таблице.

**Что будет дальше:**
1. Перенос выполняется только после вашего файла.
2. Dry-run — отчёт о каждой проблеме строки, ничего не меняется.
3. Если в dry-run нет ошибок: перенос в копию, сверка с таблицей и оракулом, затем `WMS_PROD.ods`.
4. Любая ошибка dry-run — остановка и вопрос вам.
