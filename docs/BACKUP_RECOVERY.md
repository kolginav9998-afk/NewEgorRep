# WMS — резервные копии и восстановление

Руководство для кладовщика и ответственного за WMS. Все кнопки — на листе «Главная».

## 1. Что где лежит

Рабочая папка WMS (одна на склад):

| Что | Где | Можно ли удалять |
|---|---|---|
| Рабочая книга | `WMS_PROD.ods` | нет |
| Журнал операций | `WMS_Journal/WMS_journal_ГГГГ-ММ.csv` — каждая проведённая операция, по одной строке | **никогда**: журнал — главная защита учёта |
| Блокировка | `WMS_Journal/wms.lock` — WMS открыта | нет; снимается кнопкой «Снять блокировку WMS» |
| Резервные копии | `WMS_Backups/` — копии книги | старые удаляет сама WMS (ротация) |
| Снимки для инструментов | `WMS_Export/` — только чтение | да, когда инструменты их больше не используют |

Файлы переноса и отчёты о нём (`tools/migrate.py`) хранятся отдельно и для работы не нужны.

## 2. Резервные копии

- **Ежедневная** — автоматически при первом запуске WMS за день. Хранятся 14 последних.
- **По кнопке «Резервная копия»** — перед рискованными действиями, в конце дня, перед копированием на другой носитель. Хранятся 10 последних.
- **Перед обновлением и перед переносом** — сама WMS и импортёр (по 5).
- Копия — это книга **в последнем сохранённом состоянии**. Операции, проведённые после сохранения, есть в журнале: при восстановлении из копии WMS доводит их по журналу.
- **Раз в неделю** копируйте на другой носитель (флешку, сетевую папку) **вместе**: `WMS_PROD.ods`, папку `WMS_Journal/` и папку `WMS_Backups/`. Копия без журнала восстанавливает книгу только на момент сохранения.
- «Проверка перед работой» предупреждает, если копий нет или последней больше 7 дней.

## 3. Каждый день

1. Откройте `WMS_PROD.ods` (макросы разрешены: папка WMS — доверенное расположение).
2. На «Главной»:
   - «Состояние» должно быть «Работа разрешена» (зелёным);
   - нажмите «Проверка перед работой»: ошибок быть не должно, предупреждения прочитайте.
3. Работайте. Сохраняйте книгу (Ctrl+S) в течение дня и перед закрытием. Проведённые операции не теряются и без сохранения — они в журнале. Но сохранение сокращает восстановление при следующем запуске.
4. Закрывайте книгу обычным способом: при закрытии WMS снимает блокировку.

## 4. Если WMS заблокирована

WMS не разрешает проводить, пока данные не согласованы. На «Главной» написано, **что случилось** («Причина») и **что сделать** («Что сделать»). Частые случаи:

| Состояние | Что это | Что сделать |
|---|---|---|
| `[TAIL]` хвост журнала | ПК выключился или LibreOffice закрылся без сохранения после проведения | «Восстановить»: операции из журнала будут доведены в книге ровно один раз. Если проводить их нельзя — «Отложить хвост журнала»: они останутся в журнале для ручной сверки, номера не переиспользуются |
| `[LOCKED]` WMS уже открыта | книга открыта в другом окне или на другом ПК, либо LibreOffice упал | закройте другое окно. Если другой WMS точно нет — «Снять блокировку WMS» |
| `[LOCK_LOST]` | блокировку перехватил другой экземпляр | закройте эту книгу **без сохранения** и откройте заново |
| `[NOT_REGISTERED]` не рабочий файл | открыта копия или книга перенесена в другую папку | если книга перенесена намеренно — «Сделать рабочим файлом». Резервную копию так не открывают — см. раздел 5 |
| `[JOURNAL_BEHIND]` журнал отстаёт | книгу перенесли без папки `WMS_Journal` | верните папку журнала рядом с книгой. Если журнала нет совсем — «Сделать рабочим файлом» (начнётся новый журнал) |
| незавершённая операция (`ROLLBACK_FAILED`, `COMMIT_FAILED`, `JOURNAL_UNCERTAIN`, …) | сбой посреди проведения | закройте книгу и откройте заново: запуск сам откатит или доведёт операцию |
| другое | служебные данные повреждены | **не сохраняйте книгу**. «Самопроверка» покажет подробности; нужна сверка по журналу и резервной копии (раздел 5) |

## 5. Восстановление из резервной копии

Когда: рабочая книга повреждена, случайно удалена или перезаписана.

1. Закройте WMS. Скопируйте в сторону повреждённую книгу и папку `WMS_Journal/` (для разбора). Папку журнала **не удаляйте и не меняйте**.
2. Возьмите из `WMS_Backups/` самую свежую копию. Скопируйте её **на место** рабочей книги под именем рабочей книги (`WMS_PROD.ods`). Открывать копию прямо в `WMS_Backups/` бесполезно: там WMS проводить не даст.
3. Откройте книгу. WMS увидит, что журнал впереди книги (хвост) — нажмите «Восстановить»: операции после сохранения копии будут доведены по журналу.
4. Нажмите «Самопроверка»: ошибок быть не должно. Затем «Резервная копия».

Если журнал потерян, книга восстанавливается только на момент копии. Операции после неё придётся провести заново по бумагам. Поэтому журнал копируется на другой носитель вместе с книгой.

## 6. Перенос WMS на другой ПК или в другую папку

1. Закройте WMS на старом месте.
2. Скопируйте **вместе** `WMS_PROD.ods` и `WMS_Journal/` (и при желании `WMS_Backups/`).
3. Откройте книгу на новом месте → «Сделать рабочим файлом» → «Проверка перед работой».
4. На старом месте книгой больше не пользуйтесь.

## 7. Чего не делать

- Не удалять и не править файлы журнала.
- Не открывать и не сохранять рабочую книгу с выключенными макросами. Если так случилось, при следующем запуске WMS проверит книгу целиком.
- Не сохранять книгу в другом формате (xlsx) — только ODS.
- Не держать две «рабочие» копии WMS: одна книга — один журнал — одно место.
- Не нажимать «Снять блокировку WMS», если WMS открыта на другом ПК.
