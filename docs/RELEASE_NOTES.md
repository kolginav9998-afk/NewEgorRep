# WMS — примечания к выпуску

## 0.6.0 — кандидат в рабочую версию (WMS_PROD_CANDIDATE)

**Версии:** продукт `0.6.0`, ядро `0.6.0-final-core`, схема служебных данных `WMS-SYS-3`, формат журнала `J1`.
**Проверено на:** LibreOffice 24.2 (Linux); книга, сохранённая в 24.2, открывается в 26.2 и обратно.
**Статус:** кандидат. Рабочей версией становится после проверки на складском ПК (пакет проверки ПК) и переноса настоящих остатков (`tools/migrate.py`).

### Что умеет WMS

- **Приход по заказу** (лист «Заказы»): заказ → приход → новый ЕИ → «Наличие»; частичные поставки, несколько УПД, исправление, сторно, отмена заказа или остатка.
- **Приход не по заказу** (лист «Иной приход»): Офис, Производство, Детали, Старый склад, Иной.
  - Одна деталь — один ЕИ: повторный приход того же артикула пополняет тот же ЕИ.
  - «Иной» — ЕИ «Требует разбора»; «Разобрать» — тип выбирается явно.
- **Выдача** (лист «Выдачи»): ЕИ → количество → получатель → дата; исправление и сторно.
- **Возврат** (лист «Возврат»): к конкретной выдаче, в остаток того же ЕИ.
- **Корректировки** (лист «Корректировки»): перемещение ЕИ на другое место, списание, инвентаризационная корректировка. Исправление и сторно каждой.
- **«Наличие»** — постоянный реестр ЕИ: остаток, место, состояние, источник.
- **Надёжность:**
  - каждая операция записывается во внешний журнал `WMS_Journal/`;
  - после сбоя или выключения — «Восстановить»;
  - Ctrl+Z проведение не отменяет;
  - проведённые строки защищены, копии строк распознаются.
- **Резервные копии** `WMS_Backups/`: ежедневная автоматическая и по кнопке.
- **Инструменты:** «Экспорт для инструментов» (снимок для WMS_TOOLBOX), «Загрузить пакет» (строки от инструментов проводятся обычными проверками).
- **Перенос старого склада:** `tools/migrate.py` (проверка → перенос в копию → сверка → рабочая книга); ЕИ сохраняют свои номера.
- **Состояние и проверки:**
  - «Состояние системы» — версии, рабочий файл, журнал, копии, размер;
  - «Проверка перед работой» — LibreOffice, макросы, запись журнала и копий, автосохранение, размер книги, защиты листов;
  - «Самопроверка» — полная сверка служебных данных.

### Что нового в 0.6.0 (Final Core)

- Лист «Корректировки»: `MOVE`, `WRITE_OFF`, `INV_ADJ` с исправлением и сторно; сторно прихода запрещено, пока у ЕИ есть действующие корректировки.
- «Экспорт для инструментов» (`WMS-SNAPSHOT-1`) и «Загрузить пакет» (`WMS-BATCH-1`) — `docs/EXPORT_CONTRACT.md`.
- Операция переноса `MIGRATE` и импортёр `tools/migrate.py`.
- «Состояние системы», «Проверка перед работой», лист «Справка», проверка совместимости LibreOffice.

### Совместимость

- **Книги этапов 1–5** (схемы `WMS-SYS-1`, `WMS-SYS-2`) ядро 0.6.0 не открывает: запуск блокируется с понятной причиной. Данные переносятся импортёром в новую книгу.
- **LibreOffice:**
  - проверенные версии (24.2, 26.2) — без замечаний;
  - другая версия 7.x и новее — предупреждение: до работы с настоящими данными выполните пакет проверки ПК;
  - версия старше 7 — ошибка «Проверки перед работой».
- **Формат книги** — только ODS.

### Ограничения

- Разделения ЕИ (split) и пересчёта единиц нет; перемещение — только ЕИ целиком.
- Скорость открытия и сохранения на складском ПК ещё не измерена (облачные замеры — в отчётах этапов).
- Нет принудительной записи журнала на диск (fsync).
- Отдельные инструменты (WMS_TOOLBOX) — следующий выпуск.
