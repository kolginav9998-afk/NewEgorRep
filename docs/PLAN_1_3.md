# PLAN_1_3 — предложения 1.3: 133 нововведения от разных профессий и новые вкладки-справочники (03.11.2026)

Это **очередь предложений**, а не задание: ничего из таблиц ниже не запущено, пока пользователь не выберет номера. Составлено по просьбе пользователя («предложи минимум 100 нововведений для общей WMS от разных профессий, чтобы сделать её идеальной»).

**Рамки те же, что всегда:** WMS полностью локальна (ни сети, ни облака, ни внешних программ); принтер этикеток — только с официальным драйвером; сохранность данных важнее новых функций; рабочий файл не меняется автоматически; любая запись данных — только через журнал; обновление — мастером в новую папку со сверкой каждой ячейки.
**Что уже есть и здесь не предлагается** — в `docs/OPERATOR_GUIDE.md`. **Ранее отклонено и не предлагается снова:** сканер штрихкодов, этикетки при приёме одним шагом, заявка поставщику (документ), напоминания о поверке и сроках, режим «только просмотр» для руководителя, отчёт по категориям.

**Как читать таблицы.** «Размер»: S — небольшое, M — среднее, L — крупное (новый учёт, новые операции журнала). «Журнал»: *нет* — только просмотр, печать или справочник (данные учёта не трогаются), *да* — новая запись в журнал по обычным правилам (проверка до записи, сторно, независимая проверка журнала в тестах).

## Какие ещё вкладки-справочники сделать (по образцу «Метизов» и «Инструмента ЧПУ»)

Каждая вкладка — свой справочник из «Наличия» по названию и категории: тип, размер и остальные признаки раскладываются по столбцам, есть «Найти», фильтры по столбцам, «Скрыть нулевые», ЕИ, места, остаток, пометка «ниже минимума». Только просмотр: учёт не меняется.

## Как выбрать
Напишите номера идей (например: «1, 2, 44, 47, 86») или номера вкладок (В1, В3, В14) — или «делай мой выбор». Идеи размера L обсуждаются отдельно: у них новый учёт и новые операции журнала.
