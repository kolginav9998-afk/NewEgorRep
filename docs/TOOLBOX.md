# WMS_TOOLBOX — отдельные инструменты WMS

Инструменты работают **со снимком** рабочей WMS и **никогда не открывают рабочую книгу** (`WMS_PROD.ods`).
- **Снимок:** в WMS — «Главная» → «Экспорт для инструментов». Появляется папка `WMS_Export/WMS_SNAPSHOT_…` рядом с книгой.
- **Возврат изменений:** изменения склада инструмент возвращает только **пакетом** (`WMS_Batches/*.csv`). В WMS — «Главная» → «Загрузить пакет»: WMS проверяет пакет целиком и проводит каждую строку обычной операцией.
- **Контракт:** `EXPORT_CONTRACT.md`.

## Где что лежит

```
<папка склада>/
  WMS_PROD.ods, WMS_Journal/, WMS_Backups/, WMS_Export/   ← рабочая WMS
  WMS_Batches/                                             ← пакеты инструментов для WMS
  WMS_TOOLBOX/                                             ← эта папка
    WMS_TOOLBOX.ods     единая точка входа (открывает инструменты по относительным путям)
    WMS_*.ods           инструменты
    reconcile/ backup/ labels/   скрипты (python3, только стандартная библиотека)
```

Папки снимков и пакетов по умолчанию — `../WMS_Export` и `../WMS_Batches`, то есть рядом с папкой инструментов. Их можно поменять на листе «Настройки» каждого инструмента.

## Инструменты

| Файл | Назначение | Что пишет |
|---|---|---|
| `WMS_INVENTORY.ods` | инвентаризация: снимок → пересчёт (фактический остаток) → разница → пакет корректировок | пакет «Корректировки» (инвентаризация) |
| `WMS_ANALYTICS.ods` | сводка: остатки, стоимость, источники, категории, места, движения по месяцам, просрочка, оборачиваемость, получатели, проблемные позиции | ничего |
| `WMS_MANAGER.ods` | отчёт руководителю за день / неделю / месяц и ручной «Журнал работы» (погрузка, погрузчик, бухгалтерия, закупки…) | PDF отчёта (`../WMS_Reports`) |
| `WMS_SEARCH.ods` | поиск ЕИ, артикула, наименования, места, получателя; карточка ЕИ с историей | ничего |
| `WMS_DOCTOR.ods` | аудит снимка и журнала: целостность, версии, защиты листов, остатки против движений, связи, дубли, счётчики, артикулы деталей; план действий | ничего |
| `WMS_LABELS.ods` | этикетки ЕИ (ЕИ крупно, наименование, артикул, место, штрихкод Code 128); печать через системный принтер, PDF | PDF (`../WMS_Labels`) |
| `WMS_DOCS.ods` | акты: передача, передача деталей (у каждой позиции артикул), передача сторонней организации (организация обязательна); позиции вручную или из выдач WMS; ODT, PDF; история и сквозной номер (занятый номер не перезаписывается) | ODT/PDF (`../WMS_Docs`) |
| `WMS_ARCHIVE.ods` | размер рабочей книги, месяцы истории, архивные пакеты с SHA-256, просмотр пакетов | `../WMS_Archive/ARCHIVE_…` |
| `WMS_IMPORTER.ods` | таблица поставщика (CSV, ODS, XLSX) → сопоставление колонок → проверка по правилам WMS и поиск повторов (в файле и с WMS по снимку) → «Предпросмотр» → пакет «Иной приход» или «Заказы» | пакет для WMS |
| `reconcile/wms_reconcile.py` | сверка старых названий, записанных от руки, с ЕИ снимка: до 5 кандидатов, уверенность и способ (точное, артикул, похожее); человек отмечает «да» → соответствие старых названий и ЕИ; ничего не списывает | отчёт и соответствие CSV |
| `backup/wms_healthcheck.py` | проверка перед сменой: книга, защиты листов, целостность книги и последней копии, журнал, блокировка, копии, свободное место, права, версии (книга читается потоково — секунды даже на 250 000 строк) | отчёт |
| `backup/wms_backup.py` | копия книги, журнала, копий WMS, книг инструментов (журнал работы, история актов) и актов на другой носитель с проверкой SHA-256 и ротацией | `WMS_BACKUP_…` на носителе |
| `labels/tspl_labels.py` | этикетки командами TSPL для термопринтера (если нет драйвера CUPS) | файл / устройство принтера |

## Команды скриптов

```
python3 reconcile/wms_reconcile.py НАЗВАНИЯ.csv --export ../WMS_Export --out сверка.csv
python3 reconcile/wms_reconcile.py --confirm сверка.csv --export ../WMS_Export --out соответствие.csv
python3 backup/wms_healthcheck.py --wms ..
python3 backup/wms_backup.py --wms .. --to /media/флешка/WMS_КОПИИ --keep 8
python3 labels/tspl_labels.py --export ../WMS_Export --ei 201,206x2 --out /dev/usb/lp0
```

Коды выхода: 0 — без замечаний; 1 — предупреждения (healthcheck) или ошибки отметок (соответствие); 2 — ошибка.

Сверку и соответствие можно запускать и из `WMS_TOOLBOX.ods` — кнопки «Сверка названий» и «Соответствие по сверке». Отчёт сверки открывается в LibreOffice: в колонке «подтвердить» напишите «да» у верного ЕИ каждого названия (или впишите ЕИ сами у строки «нет кандидатов») и сохраните файл в формате CSV.

## Обновление набора

`tools/build_toolbox.py` собирает набор только в новую папку: в книгах работающего набора — данные людей («Журнал работы» WMS_MANAGER, история и номер актов WMS_DOCS, настройки). При обновлении соберите новый набор рядом, перенесите эти листы и замените папку.

## Правила безопасности

- **Книга WMS не меняется.** Инструменты не открывают `WMS_PROD.ods`. Снимок проверяется по `manifest.csv` (SHA-256) до чтения: изменённый снимок инструмент не использует.
- **Пакет проводит только WMS.** Каждая строка пакета — обычная операция WMS со всеми проверками. Строка, остаток которой изменился после снимка (инвентаризация), не проводится — нужен пересчёт.
- **Один пакет — один раз.** Повторная загрузка того же пакета — отказ.
- **Архив ничего не удаляет из рабочей книги.** Сокращение книги — только отдельной подтверждаемой процедурой обновления с проверкой восстановления.
- **Повтор не проводится молча.** Массовый приход с повтором (в файле или с тем, что уже есть в WMS) пакет не создаёт; настоящее повторное поступление проводится в WMS вручную.
