## 0. Итог

- **`tools/migrate.py`** — импортёр в четыре шага: DRY RUN → MIGRATE COPY → VERIFY → PROMOTE.
  - Исходная книга не изменяется; перенос выполняется целиком или никак.
  - Каждая строка таблицы — одна операция ядра `MIGRATE` с происхождением «таблица | SHA-256 | строка».
  - ЕИ сохраняют номера; строка без ЕИ получает новый номер выше всех.
  - Проверка копии — сверкой с таблицей, самопроверкой и независимым оракулом.
- **Стоп-условия задания** — все блокирующие, перенос не начинается:
  - конфликт ЕИ (дубль в таблице, ЕИ уже в книге);
  - артикул детали у нескольких ЕИ;
  - неизвестная единица, неизвестное место;
  - пустой тип источника без `--default-source` (D-087);
  - отрицательное или неверное количество;
  - строка без ключевых данных.

  Неизвестная единица и место в dry-run этапа 5 были предупреждениями; при переносе это остановка. Места берутся из списка (`--places`) или принимаются из таблицы только явно (`--accept-table-places`) — как `--default-source`.
- **`WMS_PROD_CANDIDATE`** — `tools/build_release.py`: папка выпуска с рабочей книгой, документами, инструментами переноса (вместе с независимым оракулом сверки: папке выпуска ничего из репозитория не нужно) и манифестом SHA-256. В книге:
  - версия на «Главной»;
  - **«Состояние системы»**, **«Проверка перед работой»**;
  - проверка совместимости LibreOffice при запуске и в проверке;
  - лист **«Справка»** — примечания к выпуску и руководство по резервным копиям и восстановлению.
- **Тесты** — один полный набор на одном коде (`TEST_REPORT.md`): перенос — **20 PASS** (MG01–MG07), кандидат — **15 PASS** (C01–C06), Final Core — **83**, этапы 5…1 — **156 / 169 / 148 / 77 / 80** PASS; окна — 4, 8, 16, 15, 10, 7 из стольких же; 0 FAIL, 0 SKIP; компиляция — OK.

## 1. Импортёр `tools/migrate.py`

| Шаг | Команда | Что делает | Результат |
|---|---|---|---|
| DRY RUN | `migrate.py dry-run ТАБЛИЦА --book КНИГА [--places F \| --accept-table-places] [--units F] [--default-source T] [--report R]` | проверки `migration_dryrun.py` + стоп-условия переноса; план: номер каждой строки, новые номера, NEXT_EI | отчёт; код 0 — можно переносить, 1 — стоп |
| MIGRATE COPY | `migrate.py copy ТАБЛИЦА --book КНИГА --out ПАПКА [те же ключи]` | повторяет dry-run; книга должна быть закрыта (нет `wms.lock`); `ПАПКА/backup/` — копия книги и журнала; копия книги и журнала в `ПАПКА`; WMS открывает копию (регистрирует её), одна операция `MIGRATE` на строку, перестройка индекса деталей, самопроверка | `MIGRATION_REPORT.md`; при любом отказе папка удаляется целиком, `ПАПКА_MIGRATION_FAILED.md` |
| VERIFY | `migrate.py verify ТАБЛИЦА --dir ПАПКА` | каждая строка — одна операция `MIGRATE` с SHA-256 этой таблицы и одна карточка «Наличие» (номер, наименование, артикул, единица, количество, место, категория, состояние, тип); NEXT_EI выше всех; самопроверка; оракул (журнал воспроизводится независимо) | `VERIFY_REPORT.md` с SHA-256 проверенной книги |
| PROMOTE | `migrate.py promote --dir ПАПКА --to РАБОЧАЯ_ПАПКА [--name WMS_PROD.ods]` | только проверенная и **не изменённая после проверки** копия (SHA-256); книга и журнал в новую папку, регистрация рабочим файлом | `PROMOTE_REPORT.md`; состояние «работа разрешена» |

Столбцы таблицы (заголовки в любом порядке, синонимы допустимы): ЕИ, Наименование, Артикул, Единица, Количество, Место, Категория, Тип источника, Старая маркировка, Комментарий. Форматы: CSV UTF-8 / Windows-1251 (разделитель `;` или `,`), ODS, XLSX.

## 2. WMS_PROD_CANDIDATE

- **Сборка:** `python3 tools/build_release.py ПАПКА` → `WMS_PROD_CANDIDATE.ods` (рабочий режим PROD, пустой реестр, тестовые швы не действуют), `docs/` (RELEASE_NOTES, BACKUP_RECOVERY, EXPORT_CONTRACT), `tools/` (перенос), `RELEASE_MANIFEST.csv`.
- **Бинарная книга в Git не хранится** (D-009): выпуск всегда собирается из исходников.
- **Совместимость LibreOffice** (`WmsStatus.LoCompat`), работа не блокируется, учёт защищён журналом:
  - проверенные версии 24.2 и 26.2 — без замечаний;
  - другая 7.x и новее — заметка запуска «ВНИМАНИЕ…» и предупреждение проверки;
  - старше 7 или неизвестная — ошибка «Проверки перед работой».
- **«Состояние системы»** (раздел «Главной»): версии продукта, ядра и схемы; состояние; экземпляр и режим; рабочий файл и его регистрация; LibreOffice; журнал (папка, последняя операция, файл); резервные копии (число, последняя, возраст); размер книги и число строк движений (ориентир 250 000).
- **«Проверка перед работой»** — только чтение, итог в окне и в разделе:
  - WMS (работа разрешена);
  - LibreOffice;
  - файл (ODS, запись);
  - макросы (уровень безопасности, доверенное расположение);
  - запись в папку журнала (пробный файл);
  - резервные копии — запись; предупреждение, если копий нет или последней больше 7 дней;
  - автосохранение документа (предупреждение, если включено);
  - размер (предупреждение после 80 % ориентира);
  - защиты: листы защищены (кроме «Получатели» — список ведётся вручную), служебные листы скрыты, структура книги защищена; иначе — предупреждение с названиями листов (`WmsStatus.Protections`);
  - непроведённые строки и несохранённые изменения.
- **Снимок для инструментов** дополнен строками manifest `sheet;лист;защищён;виден` и `structure;защищена` — для проверки защит в WMS_DOCTOR (контракт только дополнен: `docs/EXPORT_CONTRACT.md`).
- **«Справка»** — `docs/RELEASE_NOTES.md` и `docs/BACKUP_RECOVERY.md`, собранные в книгу (без разметки), лист защищён.

## 4. На утверждение

| № | Правило | Почему так |
|---|---|---|
| П-13 | Неизвестная единица и неизвестное место при переносе — остановка (в dry-run этапа 5 — предупреждения); места известны из списка `--places` или книги; `--accept-table-places` принимает места таблицы только явно | задание §4: «unknown unit or place» — стоп; как D-087 — правило задаётся явно |
| П-14 | Пустое место и нулевое количество при переносе — предупреждения, не стоп (ЕИ с нулевым остатком сохраняется) | реальные старые остатки бывают без места; ЕИ сохраняет номер и наклейку |
| П-15 | Строка без ЕИ получает новый номер выше всех номеров таблицы и книги (нужна новая наклейка — список в отчёте) | принято в dry-run этапа 5; номера не перенумеровываются |
| П-16 | PROMOTE — только после VERIFY без расхождений и если копия не менялась после проверки; рабочая книга по умолчанию `WMS_PROD.ods` | задание §4: VERIFY → PROMOTE; §11 — `WMS_PROD.ods` |
| П-17 | Совместимость LibreOffice: проверенные 24.2 и 26.2; другая версия ≥ 7 — предупреждение (не блокировка); < 7 — ошибка проверки перед работой | блокировать склад по номеру версии опаснее; складской ПК проверяется пакетом M5 |
| П-18 | Снятая защита листа, открытый служебный лист, незащищённая структура книги — предупреждение «Проверки перед работой» (не блокировка); «Получатели» — без защиты | защита — от случайной правки; учёт защищён журналом, контролем строк и самопроверкой |
